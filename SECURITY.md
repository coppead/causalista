# Security policy

*Em português: se encontrar um problema de segurança, não abra uma issue pública; use o canal privado de relato do GitHub neste repositório ("Security" → "Report a vulnerability").*

Causalista is a research release: a model, its training data and the code that generates, verifies and evaluates them. It runs locally and does not call any network service on its own.

If you find a security problem (for example, in how the runner reads a table, or in a dependency), please do not open a public issue. Use GitHub's private vulnerability reporting on this repository ("Security" → "Report a vulnerability"). You will get an answer within two weeks. Only the latest release (0.1.x) receives fixes.
